## 📖 项目简介

本项目是 GitHub 上最知名的算法学习库之一 TheAlgorithms/Python 的中文翻译版。原项目用 Python 实现了数百种经典算法与数据结构，覆盖排序、搜索、图论、动态规划、机器学习、神经网络、密码学、量化金融等数十个方向，代码全部经过社区评审与持续集成测试。

所有实现均以教学为目的，帮助读者理解算法思想与 Python 编程技巧，而非追求工业级性能（生产环境请优先使用 Python 标准库或 NumPy/SciPy 等成熟方案）。本仓库将原项目的说明文档翻译成地道中文，方便中文读者快速上手与检索。

## ✨ 主要特性

- 🎯 **算法种类齐全**：排序、搜索、动态规划、贪心、回溯、分治、图论、数论等经典算法一应俱全
- 🧮 **数学与科学计算**：数值分析、线性代数、分形、模糊逻辑、量子计算、物理模拟等专题实现

- 📚 **教学导向**：每个算法附带源码与注释，适合对照学习、课后练习与面试复习

## 🚀 快速开始

1. 克隆原项目仓库（完整源代码在原项目）：

```bash
git clone https://github.com/TheAlgorithms/Python.git
cd Python
```

2. 确认本地已安装 Python 3（建议 3.9 及以上版本）：

```bash
python --version
```

3. 直接运行任意感兴趣的算法脚本，例如希尔排序：

```bash
python sorts/shell_sort.py
```

4. 运行部分文件需要第三方依赖，可按需安装（以 numpy 为例）：

```bash
pip install numpy
```

5. 浏览原项目 [DIRECTORY.md](https://github.com/TheAlgorithms/Python/blob/master/DIRECTORY.md) 目录索引，按分类查找目标算法。

完整源代码与最新版本请访问原项目：https://github.com/TheAlgorithms/Python
